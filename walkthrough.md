## 3. Critical Bug Fixes (The "Broken Flows")

### A. Firestore Timestamp Validation Bug
- **Issue**: Toggling the "Featured" status on Events would fail with a "Data is Invalid" error even if the data was correct.
- **Root Cause**: The Zod validator in the backend was checking raw Firestore `Timestamp` objects against a schema expecting `Date` objects or `ISO strings`.
- **Fix**: Patched `adminCms.ts` to normalize all Firestore Timestamps into native JavaScript `Date` objects *before* running the Zod validation pass.

### B. Legacy Document Resilience
- **Issue**: Older documents missing newly added required fields (like `imageAlt`) would fail status-only updates.
- **Fix**: 
    - Updated `validators.ts` to make non-essential fields (SEO titles, descriptions, etc.) `.optional()` for updates.
    - Enhanced the CMS UI to catch `fieldErrors` and display specifically which fields are missing in a toast notification.

### C. Windows Build Deadlock
- **Issue**: `npm run build` would hang indefinitely on Windows due to `fs.rmSync` deadlocks on locked files in the `.next` cache.
- **Fix**: Refactored `scripts/cleanNextDevCache.cjs` to be fully asynchronous with a 1-second `Promise.race` timeout watchdog per directory.
